# GamePulse

Учебный тематический дашборд на чистом JavaScript с ООП и ES6 Modules.

## Возможности

- динамическое добавление и удаление виджетов;
- независимое состояние каждого экземпляра;
- Dota 2 профиль и последние матчи через OpenDota API;
- скидки Steam через CheapShark API;
- локальные виджеты задач и цитат;
- сворачивание и полное удаление с очисткой обработчиков событий;
- сохранение Steam account ID и задач в `localStorage`.

## Запуск

Из этой папки запустите статический сервер, например `python -m http.server 8000`, затем откройте `http://localhost:8000`.

Для Dota 2 нужен числовой Steam account ID. Его можно найти в URL профиля Steam или через OpenDota.
